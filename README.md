# Proprietary files for Bluefox Aura A1

This repository contains the proprietary runtime files required by the
LineageOS device tree for the Bluefox Aura A1 (`Aura_A1`, `BF00A`).

The files were extracted from stock build
`BLUEFOX_J583_A8_Aura_A1_EN_8_128_V1.0.0_20260610`, with fingerprint:

```
BLUEFOX/Aura_A1/Aura_A1:16/BP2A.250605.031.A3/20260610:user/release-keys
```

`Android.bp` and `Aura_A1-vendor.mk` are generated from
`device/bluefox/Aura_A1/proprietary-files.txt`; edit the manifest and
regenerate the vendor tree instead of editing those files directly.
